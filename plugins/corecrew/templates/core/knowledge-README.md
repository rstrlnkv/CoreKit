# Knowledge

Lessons learned while building, one line each, newest last:

    symptom → cause → guard

The symptom is what you saw, the cause is why it happened, the guard is the check or rule
that stops it from happening again. By hand you may write `->`; it reads the same.

Two levels:
- `<Core>/<project>/docs/knowledge/<role>.md` holds every new lesson (one file per role, such as engineer or tester).
- `<Core>/knowledge/<role>.md` holds a lesson that recurred in another project, or one that is plainly general.

`/corecrew:task` writes these lines after you say ok to them. Edit or delete any line by hand.
