# Secret file names of the second-opinion skill: the one list both filters are built from.
# One glob per line, matched against the path inside the project at any depth (a leading **/ is added).
# A name also covers everything under a folder of that name (a /** is added too, unless the line ends in /**):
# *[sS]ecret* drops secrets/config.yml as well as my-secret.txt.
# A glob may hold * ? [..] and **; no spaces, quotes or backslashes. Text after a space is a comment.
#
#  - allowed-files.sh makes each line git exclude pathspecs ':(exclude,glob,icase)**/<glob>' and
#    ':(exclude,glob,icase)**/<glob>/**': what Claude may send. It is case-insensitive.
#  - ask-gpt.sh makes each line Codex profile entries "**/<glob>"="deny" and "**/<glob>/**"="deny": what GPT may
#    open on its own. That match is case-sensitive, so the common case variants are listed ([sS]ecret, SECRET).
#
# Differences from corecrew (its git-hooks/blocked-patterns and lib.sh codex-profile; tests/test_coreopinion.sh
# checks that every secret name corecrew blocks is dropped here too). This list is wider on purpose, since
# what passes goes to OpenAI:
#  - every .env* name, .envrc too (corecrew leaves .envrc open as project config);
#  - any name with secret or token in it (corecrew lists narrower forms to spare source files such as
#    tokenizer.js); here those source files are left out of the material too.
